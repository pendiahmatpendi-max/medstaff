# System Actors

## Aktor Sistem

Aplikasi MedStaff memiliki dua jenis aktor utama, yaitu User dan Administrator.

---

## 1. User (Karyawan)

User merupakan seluruh pegawai Klinik Pratama Unimus yang menggunakan aplikasi untuk melakukan aktivitas sehari-hari.

### Pengguna meliputi:

- Dokter
- Perawat
- Bidan
- Petugas Administrasi
- Satpam
- Petugas Kebersihan

### Hak Akses User

- Login ke aplikasi
- Registrasi akun
- Melakukan Clock In
- Melakukan Clock Out
- Mengambil foto selfie saat absensi
- Mengirim lokasi GPS saat absensi
- Melihat riwayat absensi
- Mengelola profil pribadi
- Mengubah password
- Mengubah PIN
- Mengelola informasi pendidikan
- Mengelola pengalaman kerja
- Mengelola kontak darurat
- Melihat profil pegawai lain
- Melihat pengumuman
- Mengakses pusat bantuan
- Logout

---

## 2. Administrator

Administrator merupakan pihak yang bertanggung jawab mengelola sistem dan data kepegawaian.

Administrator terdiri dari:

- HRD
- Pimpinan Klinik

### Hak Akses Administrator

- Login ke dashboard admin
- Mengelola data pegawai
- Mengelola akun pengguna
- Melihat seluruh data absensi
- Melakukan koreksi absensi
- Mengelola pengumuman
- Melihat laporan absensi
- Memantau aktivitas pegawai
- Logout
