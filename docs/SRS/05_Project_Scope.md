# Project Scope

## Ruang Lingkup Proyek

MedStaff merupakan aplikasi mobile berbasis Android yang dikembangkan khusus untuk mendukung proses manajemen kepegawaian di Klinik Pratama Unimus.

Ruang lingkup sistem meliputi:

### 1. Autentikasi Pengguna
- Login
- Registrasi
- Lupa Password
- Logout

### 2. Manajemen Absensi
- Clock In
- Clock Out
- Selfie saat absensi
- Validasi lokasi menggunakan GPS
- Pencatatan waktu otomatis
- Riwayat absensi

### 3. Manajemen Profil Pegawai
- Informasi personal
- Informasi pekerjaan
- Kontak darurat
- Pendidikan
- Pengalaman kerja
- Ubah password
- Ubah PIN
- Pengaturan bahasa

### 4. Direktori Pegawai
- Melihat daftar pegawai
- Melihat profil pegawai lain
- Pencarian pegawai

### 5. Notifikasi
- Pengumuman dari HRD
- Notifikasi sistem
- Informasi absensi

### 6. Pusat Bantuan
- FAQ
- Panduan penggunaan
- Kontak administrator
- Tentang aplikasi

### 7. Dashboard Admin
- Kelola data pegawai
- Kelola absensi
- Kelola pengumuman
- Melihat laporan absensi
- Monitoring aktivitas pegawai

## Batasan Sistem

Sistem MedStaff pada versi pertama (Version 1.0) tidak mencakup:

- Penggajian (Payroll)
- Penjadwalan shift otomatis
- Integrasi dengan BPJS
- Integrasi dengan sistem rekam medis
- Integrasi dengan sistem rujukan rumah sakit
- Fitur chat antarpegawai
- Versi iOS
