# Glossary

## Daftar Istilah

| Istilah | Definisi |
|---------|----------|
| MedStaff | Aplikasi mobile untuk manajemen kepegawaian Klinik Pratama Unimus. |
| User | Seluruh karyawan yang menggunakan aplikasi MedStaff. |
| Administrator | HRD atau pimpinan yang memiliki hak akses untuk mengelola sistem. |
| Clock In | Proses absensi saat memulai jam kerja. |
| Clock Out | Proses absensi saat mengakhiri jam kerja. |
| Attendance | Proses pencatatan kehadiran karyawan. |
| Selfie Verification | Verifikasi identitas menggunakan foto selfie saat absensi. |
| GPS | Global Positioning System yang digunakan untuk memperoleh lokasi absensi. |
| Dashboard | Halaman utama aplikasi setelah pengguna berhasil login. |
| Profile | Halaman yang berisi informasi pribadi dan pekerjaan pengguna. |
| Employee Directory | Daftar seluruh pegawai yang terdaftar dalam sistem. |
| Announcement | Informasi atau pengumuman yang dikirim oleh administrator kepada seluruh karyawan. |
| Notification | Pesan yang diterima pengguna mengenai aktivitas aplikasi. |
| JWT | JSON Web Token yang digunakan sebagai metode autentikasi pengguna. |
| API | Application Programming Interface yang menghubungkan aplikasi mobile dengan backend. |
| PostgreSQL | Sistem manajemen basis data relasional yang digunakan pada backend. |
| Prisma ORM | Object Relational Mapping yang digunakan untuk mengakses database PostgreSQL. |
| React Native | Framework JavaScript yang digunakan untuk membangun aplikasi mobile Android. |
| NestJS | Framework backend berbasis Node.js yang digunakan untuk membangun REST API. |
| REST API | Layanan backend yang digunakan sebagai komunikasi antara aplikasi mobile dan server. |
