# User Stories

## User Stories

### Sebagai Karyawan

### US-001 Login

Sebagai karyawan, saya ingin login ke aplikasi menggunakan email dan password agar dapat mengakses fitur MedStaff.

---

### US-002 Registrasi

Sebagai calon pengguna, saya ingin membuat akun agar dapat menggunakan aplikasi MedStaff.

---

### US-003 Clock In

Sebagai karyawan, saya ingin melakukan Clock In menggunakan selfie dan lokasi GPS agar kehadiran saya tercatat secara valid.

---

### US-004 Clock Out

Sebagai karyawan, saya ingin melakukan Clock Out menggunakan selfie dan lokasi GPS agar jam pulang saya tercatat.

---

### US-005 Riwayat Absensi

Sebagai karyawan, saya ingin melihat riwayat absensi sehingga saya dapat mengetahui data kehadiran saya.

---

### US-006 Mengelola Profil

Sebagai karyawan, saya ingin memperbarui informasi pribadi agar data saya selalu sesuai.

---

### US-007 Melihat Pegawai

Sebagai karyawan, saya ingin melihat profil pegawai lain sehingga saya dapat mengetahui informasi dasar rekan kerja.

---

### US-008 Melihat Pengumuman

Sebagai karyawan, saya ingin menerima pengumuman dari HRD agar memperoleh informasi terbaru.

---

### US-009 Mengubah Password

Sebagai karyawan, saya ingin mengubah password agar akun saya tetap aman.

---

### US-010 Mengubah PIN

Sebagai karyawan, saya ingin mengubah PIN agar keamanan aplikasi meningkat.

---

## Sebagai Administrator

### US-011 Mengelola Pegawai

Sebagai administrator, saya ingin mengelola data pegawai sehingga seluruh informasi pegawai tetap akurat.

---

### US-012 Mengelola Absensi

Sebagai administrator, saya ingin melihat dan mengelola data absensi seluruh pegawai.

---

### US-013 Mengelola Pengumuman

Sebagai administrator, saya ingin membuat, mengubah, dan menghapus pengumuman agar informasi dapat tersampaikan kepada seluruh pegawai.

---

### US-014 Melihat Laporan

Sebagai administrator, saya ingin melihat laporan absensi sehingga dapat melakukan evaluasi kehadiran pegawai.
