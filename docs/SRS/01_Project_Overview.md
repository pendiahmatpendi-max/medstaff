# Project Overview

## Project Name

**MedStaff – Workforce & Attendance Management System for Klinik Pratama Unimus**

---

## Project Description

MedStaff merupakan aplikasi mobile berbasis Android yang dikembangkan untuk mendukung proses manajemen kepegawaian di Klinik Pratama Unimus. Aplikasi ini berfungsi sebagai sistem terintegrasi yang memudahkan pengelolaan absensi, data pegawai, informasi pekerjaan, serta komunikasi internal antara karyawan dan pihak manajemen.

Sistem absensi menggunakan metode selfie yang dipadukan dengan pencatatan waktu (Clock In dan Clock Out) serta lokasi GPS secara otomatis untuk meningkatkan keakuratan data kehadiran.

Selain absensi, MedStaff menyediakan fitur pengelolaan profil pegawai, informasi pekerjaan, riwayat pendidikan dan pengalaman, kontak darurat, notifikasi, serta pengaturan akun sehingga seluruh data kepegawaian dapat dikelola dalam satu aplikasi.
