# MEDSTAFF — ADMIN MOBILE WIREFRAME

**Aplikasi Manajemen Kepegawaian Klinik Pratama Unimus**

## 1. ADMIN OVERVIEW

Admin adalah HRD atau pimpinan Klinik Pratama Unimus yang bertugas mengelola data pegawai, shift, jadwal, absensi, kegiatan, pengajuan, pengumuman, dan sistem.

### Admin Navigation

```text
ADMIN
│
├── 🏠 Dashboard
│
├── 👥 Manajemen Pegawai
│
├── 🕐 Kelola Shift
│
├── 📅 Jadwal Bulanan
│
├── ✓ Monitoring Absensi
│
├── 📋 Kegiatan
│
├── 📝 Persetujuan
│
├── 📢 Pengumuman
│
├── 🔔 Notifikasi
│
├── 👤 Profil
│
└── ⚙ Pengaturan
```

# 28. IMPORTANT UI RULES

AI UI Generator harus mengikuti aturan berikut:

1. Aplikasi adalah **mobile application**.
2. Semua halaman menggunakan desain yang konsisten.
3. Admin menggunakan **navigation drawer** atau menu Admin.
4. Dashboard menjadi halaman utama Admin.
5. Gunakan card untuk ringkasan statistik.
6. Gunakan list untuk data pegawai, absensi, kegiatan, dan pengajuan.
7. Gunakan modal/dialog untuk konfirmasi:

   * Approve
   * Reject
   * Delete
   * Cancel Activity
8. Status menggunakan indikator visual:

   * Pending
   * Approved
   * Rejected
   * Active
   * Inactive
   * Hadir
   * Terlambat
   * Tidak Hadir
   * Belum Absen
9. Semua form memiliki validasi.
10. Semua aksi penting memiliki confirmation dialog.
11. Dashboard harus dapat melakukan navigasi cepat ke halaman detail.
12. Tampilan harus responsive untuk berbagai ukuran smartphone.
13. Gunakan bahasa Indonesia.
14. Nama aplikasi: **MedStaff**.
15. Nama institusi: **Klinik Pratama Unimus**.
